# Project Sentinel RP

Repository pengembangan platform roleplay FiveM Indonesia dan Sentinel Security Platform.

Status: bootstrap berdasarkan *PRD FiveM Sentinel Full v1* (26 Oktober 2026). Target 500 pemain simultan adalah target pengujian, bukan kapasitas yang telah dibuktikan; 1.000 pemain adalah stretch test.

Sebelum memasang atau menjalankan layanan, tinjau arsitektur, izin resource, konfigurasi secrets, dan proteksi upstream TCP/UDP sesuai kebutuhan FiveM. Tidak ada jaminan anti-DDoS 100%.

Perubahan berikutnya dibuat melalui branch fitur dan pull request menuju `main`.
