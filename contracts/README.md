# Event contracts (draft)

Canonical telemetry events from PRD §13.2: `connection_attempt`, `game_session`, `economic_mutation`, `game_abuse_signal`, `network_interval`, `security_incident`.

Contract ownership, transport, schemas, validation, retention and API versioning remain open. Do not transmit real player identifiers in fixtures. `contracts/event-examples.json` is synthetic sample data, **not** a validated wire format.
